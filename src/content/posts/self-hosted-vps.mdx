For a long time, I relied heavily on big tech companies to manage my digital life. From password managers to cloud storage and ad-blockers, everything was scattered across different subscriptions and proprietary platforms. Recently, I decided it was time to take back control, consolidate my tools, and build my own self-hosted infrastructure. 

The goal was simple: rent a single VPS (Virtual Private Server), containerize everything, and make it absolutely bulletproof from a security standpoint. Here is a look at my current setup, the services I run, and the reasoning behind my architecture.

## 🏗️ The Foundation: Docker & Traefik

I knew from day one that I wanted a clean, reproducible environment. Installing apps directly onto a host OS is a recipe for dependency hell, so **Docker** and **Docker Compose** were the obvious choices. Every service lives in its own isolated container, communicating through a dedicated internal Docker network.

To manage how traffic reaches these containers, I use **Traefik** as my reverse proxy. Traefik is fantastic because it listens to the Docker socket and dynamically discovers new services. It also handles SSL certificates automatically via Let's Encrypt. By using a Cloudflare DNS challenge, Traefik can generate valid certificates even for services that I refuse to expose to the public internet. 

## 🛡️ The Secret Sauce: A "Zero Trust" VPN

Here is where the architecture gets interesting. When you self-host sensitive tools—like a password manager—exposing them to the public internet is a massive risk, no matter how strong your master password is. 

Instead of relying on basic authentication, I implemented a "Zero Trust" model using **Tailscale**. Tailscale creates an invisible, peer-to-peer mesh VPN (a Tailnet) between my devices (laptop, phone) and my VPS. 

In my Cloudflare DNS settings, the subdomains for my private tools do not point to my server's public IP; they point strictly to the server's internal Tailscale IP (`100.x.x.x`). To the outside world, these subdomains don't resolve to anything useful. To me, with my Tailscale app running, they load instantly with a secure, valid HTTPS connection.

## 🌐 Public Projects

While the core of the server is locked down for my private use, I also use this VPS to host a few custom-built web applications and landing pages. 

Because of the way Traefik is configured, these public projects are routed normally. Anyone on the internet can access them, but Traefik ensures that this public traffic can never cross over into the private management network.

## 🧰 My Private Self-Hosted Stack

So, what exactly am I running behind this invisible wall?

### 1. Vaultwarden (Taking Back My Passwords)
* **Why I use it:** I wanted to escape the cycle of paying for password manager subscriptions while retaining all the premium features. 
* **What it is:** Vaultwarden is a lightweight, self-hosted server fully compatible with official Bitwarden clients. My passwords, secure notes, and 2FA tokens now live on *my* hard drive, not on a third-party cloud. Because it's locked behind Tailscale, an attacker can't even reach the login page to attempt a brute-force attack.

### 2. Syncthing (Ditching Google Drive/Dropbox)
* **Why I use it:** I needed a way to keep my files, documents, and backups synchronized across my phone, laptop, and server without worrying about storage limits.
* **What it is:** A continuous, decentralized file synchronization tool. It operates peer-to-peer, meaning my files sync directly between my devices. The VPS simply acts as an "always-on" node, ensuring that if my laptop is closed, my phone can still pull the latest files.

### 3. Termix (Modern, Web-Based SSH)
* **Why I use it:** SSH-ing into a server from a mobile device is usually a clunky experience that requires juggling private keys.
* **What it is:** Termix acts as a centralized, web-based SSH client hosted directly on the VPS. Whenever I need to run a quick command or restart a container on the go, I just open my browser, load Termix via the VPN, and I have a beautiful terminal at my fingertips. 

### 4. AdGuard Home (Network-Wide Ad Blocking)
* **Why I use it:** I hate ads, trackers, and malicious pop-ups, but installing ad-blockers on every single browser and device is tedious.
* **What it is:** A private DNS sinkhole. I configured my Tailscale network to force all connected devices to use my VPS as their DNS resolver. Now, whether I am on my home Wi-Fi or connected to a random public hotspot on my phone, AdGuard strips out the ads and trackers before they even reach my screen.

### 5. Portainer (Docker Management)
* **Why I use it:** While I love the command line, sometimes it's just faster to click a button.
* **What it is:** Portainer gives me a visual web UI to manage my Docker environment. I use it to quickly check container health, read live logs, and prune unused images.

## Wrapping Up

Building this setup took some tweaking—especially getting Traefik to play nicely with Tailscale IPs—but the result is incredibly satisfying. I now have a production-ready, air-tight environment that hosts my public projects while keeping my digital life strictly private and under my control.
